Entry for the make.fun bounty **"Make the AI Judge Laugh"** (slug `u-alfasurya91-make-the-ai-judge-laugh-6ed40225`, $2 prize pool).

`main.ts` writes a single original one-line office joke to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The joke plays on a true office ritual — chasing inbox zero — and lands with a surprising turn: IT restores the inbox from backup as a "team-building exercise."

Run it with:

```sh
node main.ts
```
